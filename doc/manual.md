# InvadeGo-Spatial
Individual based forward simulations of transposable element (TE) invasions in 2D populations.
The tool uses discrete generations and assumes individuals equally distributed on a spatial grid. 
For building the next generation mate pairs are picked in the neighborhood of each individual based on fitness.
Individuals are hermaphrodites and the sex (male, female) is randomly assigned.
